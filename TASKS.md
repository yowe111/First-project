# TASKS — где мы находимся

`ROADMAP.md` отвечает на вопрос «зачем и в каком порядке».
Этот файл — на вопрос «что делать сегодня вечером».

Правило работы: берём **одну** задачу, доводим до пункта «готово, когда»,
ставим `[x]`. Идеи, пришедшие посередине, записываем в конец файла и не
трогаем до конца фазы.

**Легенда:** `[x]` сделано · `[ ]` впереди · **←** следующая задача

## Фаза 2. Аналитическое ядро

Здесь живёт профессия. Работаем в `notebooks/`, данные — Online Retail II.

- [x] **2.1** Загрузка, распознавание колонок, очистка, отчёт о качестве,
      три первых числа — `notebooks/01_first_numbers.ipynb`
- [x] **2.2** RFM-сегментация — `02_rfm.ipynb` **←**
      Квантили по давности, частоте и сумме; сегменты с человеческими
      названиями (Чемпионы, Лояльные, Под угрозой, Спящие, Потерянные);
      для каждого — доля базы, доля выручки, средний чек.
      Готово, когда: таблица «сегмент → сколько людей, сколько денег»
      и понятно, какие три сегмента приносят больше всего.
- [x] **2.3** Когортный анализ — `03_cohorts.ipynb`
      Матрица «месяц первой покупки × месяц жизни» в людях и в выручке.
      Заготовка уже есть: колонки `cohort` и `age` считаются в ноутбуке 01.
      Готово, когда: видно, живут новые когорты дольше старых или короче.
- [x] **2.4** BG/NBD и Gamma-Gamma — `04_btyd.ipynb`
      Своя реализация через `scipy.optimize`, сверка с `lifetimes`.
      Готово, когда: обучено на первых 18 месяцах, прогноз сверен с фактом
      последних 6, известна ошибка на уровне клиента и смещение по базе.
- [ ] **2.5** Модель оттока — `05_churn.ipynb`
      Срезы по времени, признаки, LightGBM против логистической регрессии.
      Валидация **только** по времени: случайный train/test split здесь даёт
      красивые и полностью фальшивые метрики.
      Готово, когда: есть ROC-AUC, PR-AUC и lift@10% на отложенном периоде.
- [ ] **2.6** Калибровка и объяснимость
      Reliability curve, при необходимости изотоническая регрессия; SHAP →
      три причины риска на клиента.
      Готово, когда: среди клиентов с оценкой 0.7 уходит примерно 70%.
      *Без этого шага формула «деньги под риском» просто врёт.*
